## App info

Hack(H)er 2020 project
Co-created an app that can be used for community welfare. The app is built in Android Studio which uses Java as the main language. The app uses Firebase Database to store all the user information and Google 
Maps API and Google Places API. Implemented the Maps portion which gives the user’s current location and locates the area in the vicinity as an individual contribution.

## Why it is needed

One can never predict what others around them are carrying. 

Social anxiety, nervousness, fear of judgement can often get better of us.
					
It can save someone’s life.
