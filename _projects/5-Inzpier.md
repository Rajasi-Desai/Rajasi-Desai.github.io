## Description as a Tweet:

Running out of hackathon ideas? Wanna build a startup but don't know where to start? Need some inspiration?
Introducing Inzpire - all-in-one social platform to find inspiration and opportunities. 
Inspire. Investigate. Innovate. 

## Inspiration:

As hackers, we aspire to build innovative solutions to address the grand challenges faced by the modern society. 
From our experiences, we noticed the most common pitfalls for hackers is to start with an idea, and overlook the importance of understanding the problem and the target user. In other words, the problem-solution fit. 
Inspired by the Lean Canvas, we would like to build a platform to help users to find and understand problems they are interested in solving, and allow users to describe their problems, upload media (photos/ audio/ video) and react to other's pain. 
Users can browse different problems and take up a challenge. By taking up the challenge, users can contact the author for more details and conduct interviews. Users can also see what other users have done in the past and why they failed so they are not wasting their effort on the same approaches. 
Users are encouraged to post regularly updates on tackling the challenge. 
Ideally this will help solve problems without an existing solution and help hackers/ founders to find opportunities.

## What it does:

Users can register for an account and login. 
During onboarding, users can customize their profile by uploading a photo, adding skills and links for profiles such as Github/ LinkedIn to establish their online presence.
On the home page, users can browse popular challenges or select a category to see the full list.
Users can post a challenge and add a description of the problems they faced, and upload media such as photos/ audio/ videos. 
Users can take up a challenge and create a project.

## Challenges we ran into:

Time crunch was a problem. Our initial goals were ambitious (with many features included), we noticed we were short in time as we could only contribute a few hours to the project per day. Therefore, we prioritized the main features to develop.
Some of our members have minimal experience in web development, and spent a lot of time learning the basics.

## Accomplishments we're proud of:

We built a functional app (in a short span of time)!

## What we've learned:

We learnt a lot about web development using JavaScript and CSS styling
